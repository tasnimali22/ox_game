# OX Game – Tic-Tac-Toe

A simple Tic-Tac-Toe mobile game built with Flutter and Dart.

## Features

* Two-player gameplay
* Simple and responsive UI
* Win and draw detection
* Game reset functionality
* Clear game status display

## Technologies

* Flutter
* Dart
* Material Design
